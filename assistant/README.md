# GenAI Assistant

A chat page where a manager asks a question in plain English and gets the answer, the table and the SQL behind it (Q8).

**Owner:** Abdelrahman Mahmoud Mohamed (GenAI & DevOps Engineer)

---

## What goes here

* Streamlit chat page
* Text-to-SQL prompt with the Gold schema, the data dictionary and example questions
* Connection through the read-only database user; only `SELECT` statements run
* 30-question test set with known answers

## Azure equivalent

Azure OpenAI.
